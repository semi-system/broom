Diskless

Machines with no disk boot a golden straight from the server. A golden is installed and kept up to date by its maintenance machine; Save makes that work the version every machine gets at its next boot.

Maintain in the browser (VM on the server)

Runs a Windows golden in a virtual machine on this server — its screen in this browser, internet through the server — so no PC leaves the room. Games: tick the games disks; they are attached writable (as for an update machine) under their letters: install or update games, shut the VM down, then Save each disk — every machine gets it at its next boot. Windows / apps (owner): tick Keep Windows changes, then Save or Discard the golden in the Goldens table; without it the VM's Windows changes are thrown away when it stops. One VM at a time (4 CPU threads, 8 GB RAM). The golden needs broom-diskless.ps1 and no maintenance machine.

Add hardware (network card)

A Windows golden boots only on network cards it has seen. For a PC with a new card (or a new kind of PC): pick the golden and that PC, press Start, then let the PC boot from the network. It starts Windows PE, reports its card, and the server installs that card into the golden in a small VM, then saves the golden's next version (a few minutes). Identical PCs need it once. The golden needs broom-diskless.ps1 and no maintenance machine.

New golden / change one

A new golden is a blank disk. Choose its maintenance machine in the table, then on that machine pick Install … from … in the boot menu: the installer sees the golden as its disk. After the install, the menu boots the golden itself (Maintain …) for drivers, software and settings. Shut it down and press Save.
Windows golden: before the first Save, run once on the maintenance machine (PowerShell as Administrator) irm http://SERVER/broom-diskless.ps1 | iex — each machine then takes its own name (Devices page) on its first boot, kept as its base.
Linux golden: an Ubuntu installer ISO is booted from the server (the machine needs ~4 GB of RAM more than the ISO) and sets the golden up by itself. Another Debian / Ubuntu install: run once before the first Save curl -fsS http://SERVER/broom-diskless.sh | sudo sh.

Where things are kept

Old versions of goldens and iSCSI disks are kept until a drive has less than % free; then the oldest go (never one a group is held on).
Server disks are added on the Server page. A place can change only while it is empty.
